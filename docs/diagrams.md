│                                                                                                 │
│                     ┌─────────────────────────────────────────────────────────────────────────┐│
│                     │                              REFERENCE POINT                            ││
│                     │                       (Camera Center = Target Point)                    ││
│                     │                                                                         ││
│                     │                         ┌─────────────────────┐                         ││
│                     │                         │    TARGET POSITION  │                         ││
│                     │                         │    (Desired State)  │                         ││
│                     │                         └──────────┬──────────┘                         ││
│                     │                                    │                                     ││
│                     └────────────────────────────────────┼─────────────────────────────────────┘│
│                                                          │                                       │
│                                                          ▼                                       │
│                     ┌────────────────────────────────────────────────────────────────────────┐  │
│                     │                                                                        │  │
│                     │  ERROR = TARGET_POSITION - CURRENT_POSITION                           │  │
│                     │  ┌──────────────────────────────────────────────────────────────────┐  │  │
│                     │  │  ex = (tx - cx) / (frame_width/2)                               │  │  │
│                     │  │  ey = (ty - cy) / (frame_height/2)                              │  │  │
│                     │  └──────────────────────────────────────────────────────────────────┘  │  │
│                     │                                                                        │  │
│                     │  ┌──────────────────────────────────────────────────────────────────┐  │  │
│                     │  │  CONTROLLER (PID / P)                                          │  │  │
│                     │  │                                                                  │  │  │
│                     │  │  Pan_Out = KP_PAN * ex + KI_PAN * ∫ex dt + KD_PAN * d(ex)/dt  │  │  │
│                     │  │  Tilt_Out= KP_TILT*ey + KI_TILT*∫ey dt + KD_TILT*d(ey)/dt   │  │  │
│                     │  └──────────────────────────────────────────────────────────────────┘  │  │
│                     │                                                                        │  │
│                     │  ┌──────────────────────────────────────────────────────────────────┐  │  │
│                     │  │  VELOCITY & ACCELERATION LIMITER                                │  │  │
│                     │  │  ┌────────────────────────────────────────────────────────────┐  │  │
